## 2. Cozy Clinic — the original hackathon project

Before Cozy Peptide, there was Cozy Clinic — the hackathon project this
repo pivoted from (hence the "Cozy" name).

Cozy Clinic was envisioned as a game to raise millions of health-literate
learners and create a new generation of doctors and healthcare providers.

- https://cozy-clinic.vercel.app/
