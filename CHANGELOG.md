# Changelog

## v0.1.0 — 2026-11-02

First release: name a disease, get a novel AI-designed peptide compiled
to LBP-ready DNA, then close the loop with the wet lab.

**Peptide designer**

- Seven small-peptide scaffolds (knottin, cyclotide, disulfide,
  hairpin, helical, linear) with Auto default per objective, and four
  oral chassis (*S. boulardii*, *E. coli* Nissle, *L. lactis*,
  *B. subtilis* spores) with compatibility scoring.
- Muse Spark ideation steered by literature-mined briefs, a symbolic
  compiler (grammar, charge, liabilities, indices), repair loop,
  blinded specificity review, and chassis biocontainment plans.
- Vendor-ready lab handoff: codon-optimized cassettes, order CSV,
  synthesis-difficulty report, and a CRO/CDMO partner directory.
- Full run ledger with stage traces, plus Pep, a floating guide that
  tours first-timers through a live design.

**Lab Guide + wet-lab loop**

- Tracked bench steps: bind a run, order DNA, build the strain,
  verify, express, assay, consent, iterate — with outsourced
  turnaround planning and token-gated uploads (or a token-free demo).
- Standards-first templates, raw-export ingest, machine work orders,
  and consented CC0 dataset export, all available programmatically.
- Optional CRO photo check: SAM 3.1 segmentation of plates and
  microscopy with overlays, counts, per-run persistence, and a
  content-hash cache so repeats never re-call the model.

**Safety**

- Safety-by-design section with refusal demo, biosafety footer,
  server-side toxin/organ/enzyme blocklist, and RUO gating throughout.

**Platform**

- Production Docker image, CI (typecheck + lint + tests + build),
  hackathon self-scorer (`npm run score`), and an `ml/` skeleton for
  future Muse distillation on consented assay data.
